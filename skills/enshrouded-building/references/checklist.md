# Перед тем как отдать результат

Пройди по списку. Каждое «нет» — вернись и исправь.

## Алтарь и участок
- [ ] `altar.at = [0,0,0]`, уровень задан, всё внутри куба (40/80/120/160 м).
- [ ] Верх плиты вровень с полом, под плитой и на 1,5 м вокруг сплошной пол, ямы нет.
- [ ] Над плитой 2 м свободно, к алтарю ведёт широкий проход.
- [ ] `"ground": true`, под всей постройкой грунт.
- [ ] Главное здание + сад + аллея + внешняя стена (если задача не говорит иначе).

## Ходить можно
- [ ] У каждой двери с обеих сторон 3 м свободного ровного пола; колонн и мебели там нет.
- [ ] Коридоры ≥ 2 м, с дверями в них ≥ 3 м; створки не задевают друг друга.
- [ ] У каждой лестницы 3 м внизу, 2 м площадки наверху, 2 м над ступенями; ведёт куда-то.
- [ ] Проём над маршем на ряд короче, с перилами; маршей бок о бок нет.
- [ ] Прошёлся в режиме «Пешком» от входа до каждой комнаты, станка и сундука.

## Целостность
- [ ] Нет дыр в полах и крышах, нет висящих блоков, шпили касаются башен.
- [ ] Чётные двускатные крыши с балкой по коньку.
- [ ] Мебель: напольная на полу, настенная на гранях стен спиной к стене, потолочная под потолком; повороты кратны 90°.
- [ ] Размеры всех предметов и шаблонов — из данных игры.

## Функция
- [ ] У каждого ремесленника закрытая спальня под крышей; тумбочка у изголовья, сундук у двери.
- [ ] Станки каждого ремесла в своём зале рядом с мастером, все в одном здании; `use` смотрит на свободный пол.
- [ ] Нижний ремесленный этаж 5 м, если есть доменная печь.
- [ ] Склад с магическими сундуками (лучше подвал ярусами), удобный спуск.
- [ ] Комфорт: камин, стол, стулья, ковёр, свет.

## Красота
- [ ] Ось входа: портал, роза, руны, эмблема по центру; крылья симметричны.
- [ ] Палитра из 6+ материалов, основной 60–70 %, одна кровля.
- [ ] Светящиеся узоры (руны, пояса, витражи), не одиночные точки.
- [ ] Свесы, пояса, цоколь, обрамления — нет «коробки».
- [ ] Сам посмотрел скриншоты со всех сторон и срезы по этажам.

## Выпуск
- [ ] `python scripts/enshrouded_house.py check` — 0 ошибок.
- [ ] `python -m unittest scripts/test_enshrouded_house.py` — зелёные (если менял правила).
- [ ] Чертёж экспортирован и прочитан обратно один в один; лимиты 65 536 / 1 000 000 / 2 000.
- [ ] Не закоммичены `.agent`, локальный строитель, снимки миров, чужие чертежи, ключи.
- [ ] Отчёт: блоки, предметы, итог `check`, ссылка на просмотр, что не проверено в игре.
