# Форматы: проект и чертёж игры

## 1. Проект `custodian.enshrouded.house.v1`

Оси: x — восток, y — север, z — вверх; единица — воксель 0,5 м; (0,0,0) —
юго-западный угол верха плиты алтаря.

```json
{
  "schema": "custodian.enshrouded.house.v1",
  "name": "...",
  "altar": {"at": [0, 0, 0], "level": 2},
  "ground": true,
  "materials": {"stone": "Block_T3_Stone_Fancy_CRAFTING"},
  "glyphs": {"stone": "#"},
  "parts": [ ... ],
  "furniture": [ ... ]
}
```

Ключи `materials` — твои короткие имена; значения — `debug_name` из
`docs/enshrouded-houses/materials.json`. Операции `parts` выполняются по
порядку, поздние перекрывают ранние.

| op | Поля | Что делает |
|---|---|---|
| `box` | `mat`, `at`, `size[3]` | Сплошной параллелепипед |
| `walls` | `mat`, `at`, `size[3]` | Периметр прямоугольника толщиной 1 |
| `template` | `name`, `mat`, `at`, `dir` (`x`/`y`) или `rot`, `count` | Шаблон молота, `count` раз вдоль `dir`; для фундаментов и перекрытий `count: [nx, ny]` |
| `battlement` | `mat`, `at`, `size[3]`, `merlon`, `gap` | Зубцы по периметру |
| `flight` | `mat`, `at`, `dir` (`+x`/`-x`/`+y`/`-y`), `rise` | Марш на этаж шириной 4 м: `rise` 9 (этаж 4,5 м) или 11 (5,5 м). `at` — ЮЗ угол первой ступени |
| `stairs` | `mat`, `at`, `dir`, `width`, `steps` | Лестница 45° из одиночных блоков |
| `door`, `double_door` | `at`, `wall` (`x`/`y`), `flip`, `prop` | Проём 4×5 (7×7) в стене толщиной 1 и дверь игры; точка — середина низа проёма |
| `window` | `at`, `wall`, `flip`, `prop` | Проём 2×3 и рама игры; `at` — низ проёма |
| `cut` | `kind` (`door`/`window`/`opening`), `at`, `size[3]` | Вырезает объём; `door` получает все проверки двери |
| `gable` | `roof`, `gable`, `at`, `size[2]`, `ridge` (`x`/`y`), `overhang`, `cap` | Двускатная 45° с фронтонами; при чётной ширине балка `cap` по коньку |
| `shed` | `roof`, `gable`, `at`, `size[2]`, `down`, `run`, `overhang` | Односкатная крыша (приделы) |
| `tower` | `mat`, `at`, `size`, `height`, `shape` (`octagon`/`square`), `floor` | Полая башня без щелей на диагоналях |
| `spire` | `mat`, `trim`, `at`, `size`, `steep`, `shape`, `finial`, `finial_mat` | Шпиль, сужение на клетку через `steep` слоёв (2 ≈ 63°) |
| `inlay` | `mat`, `at`, `rows`, `wall` | Пиксельный рисунок в стене (`#` — блок): руны, розы, витражи |
| `pattern` | `mat`, `at`, `size`, `step`, `cell`, `only_on` | Повторяющийся узор; с `only_on` перекрашивает только этот материал |
| `replace` | `from`, `to`, `at`, `size` | Замена материала |
| `fragment` | `file`, `at`, `origin`, `rot`, `crop`, `materials`, `props` | Вставка снимка мира (`worlds/*.json`) или сцены (`custodian.enshrouded.scene.v1`) |

### `furniture[]`

| Поле | Смысл |
|---|---|
| `id` | своё имя |
| `prop` | `debug_name` предмета игры из `prop-catalog.json` (размер берётся оттуда) |
| `at` | клетка; для настенных — клетка у стены |
| `rot` | 0/90/180/270 (0 — лицом на +y, 90 — на −x, 180 — на −y, 270 — на +x) |
| `use` | сторона подхода `+x`/`-x`/`+y`/`-y` — обязательно для станков, сундуков, каминов |
| `mount` | `floor`/`wall`/`ceiling`, если автоопределение по габариту не то |
| `lift` | высота настенного предмета |
| `needs_shelter` | кровати и станки: крыша и закрытая комната |
| `walkable` | настенные/висящие вещи, которые не мешают ходу |
| `lit` | светильник ставится зажжённым (шаблон из `lit-lamps.json`) |

Настенный предмет без `rot` сам разворачивается спиной к ближайшей стене.
Потолочный вешается под первый блок над `at`.

## 2. Чертёж игры (папка bundle, `.sfbp`)

Эталон — `D:\Projects\Custodian_GM\work\enshrouded\blueprints\mayor-manor-furnished-no-stations-v1`
(локально, не публиковать). Полное описание — `docs/enshrouded-houses/blueprints/FORMAT.md`.
Пиши чертежи только через `scripts/enshrouded_bundle.py export`, не руками.

| Файл | Роль |
|---|---|
| `manifest.json` | id, статус, ссылка на алтарь, смещение пола (1,0 м), sha256 и размер каждого файла |
| `fit.json` | части, начало кадра, алтарь, `source_floor_top` |
| `<имя>-part-N.sfbp` | воксели, одна плитка; части сложены стопкой по Y |
| `<имя>-props-frame.sfbp` | предметы и ровно одна строка-маркер алтаря |
| `source-prop-aabbs.json` | габариты предметов (доказательство, что ничто не лезет в алтарь) |
| `catalog-entry.json` | карточка каталога |

Ключевое:

- В `.sfbp` оси X, **Y вверх**, Z; метры; клетка 0,5 м. Индекс
  `i = x + sx*(y + sy*z)`.
- Значение клетки: `value & 255` — материал, `value >> 8` — плотность.
  Блок игрока — материал ≥ 128, старший байт 0. Грунт — материал < 128 с
  плотностью (65282 = материал 2, плотность 255). 0 — воздух.
- Покрытие: 2 — записать клетку (ровно для ненулевых), 1 — записать воздух,
  0 — не трогать мир. Снаружи постройки ставь 0, иначе сотрёшь рельеф.
- Строка предмета: `item_id, x, y, z, qx, qy, qz, qw, sx, sy, sz, uuid_high, uuid_low`;
  поворот только вокруг Y: (0, sin(a/2), 0, cos(a/2)). У зажжённых ламп
  свой шаблон (`lit-lamps.json`).
- Файлы — LF, без перевода строки в конце; Windows-конвертация концов строк
  ломает хэши (держи `.gitattributes`).
- Сундуки приезжают пустыми.
- Строитель (`host_planner.py` + `catalog-build-transaction.lua`) грузит
  только чертёж, зарегистрированный в CatalogApproval; поворачивает весь
  чертёж четвертями вокруг алтаря; сначала воксели, потом предметы;
  неизвестный результат не повторяет.

## 3. Снимки и сцены

- `docs/enshrouded-houses/worlds/*.json` — захваты настоящих баз (особняк
  мэра, библиотека Everspire, таверна Diadwyn): изучай материалы, размеры
  комнат, лестницы, расстановку.
- Снимок World Editor вокруг алтаря: папка с `fit.json` или полный снимок
  области с `capture.json` + `part-*.sfbp` + `props.sfbp` (например «Дом 1»,
  `dom-1-v1`). Блоки игрока — материал ≥ 128.
- `enshrouded_bundle.py import <папка> -o piece.scene.json` → сцена для
  `fragment`. Импорт/экспорт — один в один.
