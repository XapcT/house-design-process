# Контракт строителя и визуализатора

Строитель — исполнитель текущего задания (в том числе внешний `enshrouded-building`). Он отвечает за проектные решения и игровые проверки. House Design отвечает за показ того же текущего spec. Отдельный чат, запуск другой модели и изменение внешнего навыка для подключения не нужны.

1. В чате исполнения вызвать `begin_house_design_session(title, request_id)` с новым локально сгенерированным UUIDv4. Сохранить возвращённые session_id и revision.
2. До детализации опубликовать настоящий текущий черновик через `update_house_design`: полный `custodian.enshrouded.house.v1` spec, `expected_revision: null`, `presentation: {stage: "sketch", intent: "Краткое видимое проектное пояснение"}`.
3. После нового проектного решения сразу передать актуальный полный spec либо `append_parts` с последней возвращённой revision. Полный spec позволяет удалять и переделывать части. Для уточнения без текстур установить stage `form`; для выбранных игровых материалов — `materials`. Эти режимы не продвигаются автоматически и не имитируют готовую работу.
4. Реальную текущую фазу без изменения геометрии передавать `set_house_design_phase`. Не заменять модель счётчиком или процентом.
5. По окончании вызвать `finish_house_design_session` с фактическим статусом. `open_house_design_app(session_id)` повторно открывает только указанную сессию.

Каждая операция имеет свой request_id; точный повтор неизвестного результата использует прежний ID. Конфликт expected_revision требует сверки состояния, а не слепой перезаписи. App доставляет неизменяемые события по порядку и продвигает курсор после коррелированного ACK viewer. Новая геометрия меняет design-owned root внутри исходной сцены, а не перезагружает документ.

Сетка относится только к нетекстурированной форме, не к земле и не к игровым текстурам. «Скрыть землю» скрывает плоскость и terrain, сохраняя модель. Управление — orbit/zoom/pan и компактные кнопки камеры.

Игровая валидация, экспорт и разрешение на запись в игру принадлежат строителю и его правилам. Успешная публикация spec в app этого не подтверждает и не даёт разрешения на игровую мутацию.
