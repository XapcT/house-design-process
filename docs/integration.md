# Строитель и визуализатор

Включены оба навыка: skills/enshrouded-building и skills/house-design. Первый отвечает за проектные решения, правила и проверку/экспорт; второй — за текущую модель в native-карточке чата. Инструменты, каталоги, модели, текстуры, viewer и хранилище находятся в этом checkout.

1. Применить оба навыка. Вызвать begin_house_design_session с title и новым локально сгенерированным request_id UUIDv4. Сохранить session_id и revision.
2. До детализации опубликовать настоящий текущий эскиз: update_house_design, полный spec custodian.enshrouded.house.v1, expected_revision=null, presentation.stage=sketch и короткое пояснение видимого замысла в presentation.intent.
3. После нового решения сразу публиковать актуальный spec либо append_parts с последней revision. Полная замена позволяет удалять отвергнутые части. form — уточнение без текстур с сеткой; materials — игровые текстуры без сетки. Эти стадии не продвигаются автоматически.
4. set_house_design_phase сообщает фактическое действие без изменения геометрии. Счётчик и фаза не заменяют проектный артефакт.
5. finish_house_design_session завершает конкретную сессию фактическим статусом; open_house_design_app(session_id) открывает её повторно без подстановки глобальной последней модели.

scripts/house_process.py предоставляет файловому исполнителю begin/publish/phase/finish через те же функции хранилища. Команды возвращают JSON с request_id и revision. Для точного повтора неизвестного результата используйте прежний --request-id; при конфликте revision сверяйте состояние, не перезаписывайте вслепую. Публикуйте созданное в текущей работе, не проигрывайте готовый дом.

MCP и WebUI используют общую SQLite внутри checkout. Браузер явно выбирает session_id и читает упорядоченные неизменяемые события; мутации через браузерный read API запрещены. WebUI использует тот же index.html через host bridge и тот же Enshrouded viewer. Курсор продвигается после коррелированного ACK; обновление меняет design-owned root, сохраняя документ, renderer, камеру, controls и canvas. Orbit/zoom/pan и скрытие земли сохраняются при новых версиях.

Черновик остаётся проектируемым, а не проверенным домом. Приёмка готового результата, checker и экспорт выполняются по правилам строителя; app не даёт разрешения на запись в игру. Исходная копия навыка сохранена без редактирования; runtime пути комплекта — scripts/ и docs/ внутри этого репозитория.
